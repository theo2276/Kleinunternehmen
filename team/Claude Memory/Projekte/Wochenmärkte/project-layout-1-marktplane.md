Seit 03.09.2026 läuft im Framer-Ordner **Layouts** das Projekt **"Layout 1"**
(Projekt-ID `n9p9pCr8T7eoeSsJpRHp`) als **kompletter Neustart** der Dienstleistungs-
website für "Websites für Marktstände und regionale Anbieter".

Verbindliche Regel des Nutzers: **nichts** aus MVP, dem Corpus-Marktstände-One-Pager,
OFM oder anderen geöffneten Framer-Projekten übernehmen — kein Farbschema, keine
Komponenten, keine Texte. Eigenes Designsystem, eigener Seitenaufbau.

Freigegebene Richtung "Marktplane": Marktblau `#14283A`, kühles Papier `#F3F3F0`,
ein Signalrot `#D64430` als einziger Akzent; Archivo (Display/Labels) + Instrument Sans
(Fließtext), kein Serif — bewusste Abgrenzung zu Corpus (Creme/Salbei/Playfair).
Breakpoints Desktop 1200 / Tablet 810 / Phone 390. Arbeitsname der Marke ist
"Marktplane" (Platzhalter, vom Nutzer noch nicht bestätigt).

"Layout 1" ist eine getrennte Template-Richtung.
