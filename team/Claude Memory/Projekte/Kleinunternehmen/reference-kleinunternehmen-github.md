`~/Kleinunternehmen` ist ein Git-Repo mit dem privaten Remote https://github.com/theo2276/Kleinunternehmen (Branch `main`, angelegt am 17.10.2026). Es enthält alle Website-Projekte (copyteam, fotostube-hornig, goefoto, grundmann, kreuzberg-on-kultour, nearmade, torben-visuals) samt Kundenfotos und muss deshalb **privat bleiben**. Ausgeschlossen sind `.DS_Store`, `.oeztest/`, `.claude/` und `node_modules/`.

Neue Arbeitsstände werden nicht automatisch hochgeladen. Sichern mit `git add -A && git commit` und `git push` – vorher kurz prüfen, dass keine Zugangsdaten in den Dateien stehen.
